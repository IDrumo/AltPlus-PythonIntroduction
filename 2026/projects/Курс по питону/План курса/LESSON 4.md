**Вопрос:** Как вывести числа от 1 до 5 с помощью `while`?  
Ответ:  
```python
i = 1
while i <= 5:
    print(i)
    i += 1
```

**Проблема:** Для простого перебора диапазона `while` требует явного управления счётчиком. У цикла `for` это проще.

### 2. Теоретическая часть

#### 2.1. Цикл `for` – для перебора последовательностей

Цикл `for` используется, когда нужно выполнить действие для каждого элемента из некоторой **последовательности** (строки, списка, диапазона чисел).

**Синтаксис:**
```python
for переменная in последовательность:
    # тело цикла
```

На каждой итерации переменная принимает следующее значение из последовательности.

**Пример со строкой:**
```python
for letter in "Python":
    print(letter)
```
Вывод: P y t h o n (каждая буква на новой строке)

**Пример со списком:**
```python
fruits = ["яблоко", "банан", "апельсин"]
for fruit in fruits:
    print(fruit)
```

#### 2.2. Функция `range()` – генератор числовых последовательностей

`range()` создаёт последовательность целых чисел. Используется в циклах `for`, когда нужно повторить действие определённое количество раз.

**Три формы вызова:**

| Форма | Пример | Результат |
|-------|--------|-----------|
| `range(stop)` | `range(5)` | 0, 1, 2, 3, 4 |
| `range(start, stop)` | `range(2, 7)` | 2, 3, 4, 5, 6 |
| `range(start, stop, step)` | `range(1, 10, 2)` | 1, 3, 5, 7, 9 |

**Важные правила:**
- `stop` не включается в последовательность.
- `start` по умолчанию 0.
- `step` по умолчанию 1. Может быть отрицательным (для убывания).
- `range()` возвращает не список, а специальный объект, но в цикле `for` ведёт себя как список чисел.

**Примеры:**
```python
for i in range(5):      # 0,1,2,3,4
    print(i)

for i in range(1, 6):   # 1,2,3,4,5
    print(i)

for i in range(10, 0, -2):  # 10,8,6,4,2
    print(i)
```

#### 2.3. Типичные задачи с `for` и `range()`

**Сумма чисел от 1 до N:**
```python
N = int(input("N = "))
total = 0
for i in range(1, N+1):
    total += i
print(total)
```

**Таблица умножения на K:**
```python
K = int(input("K = "))
for i in range(1, 11):
    print(f"{K} x {i} = {K*i}")
```

**Вывести только чётные числа от 2 до 20:**
```python
for i in range(2, 21, 2):
    print(i)
```

#### 2.4. Вложенные циклы

Цикл внутри цикла. Внутренний цикл выполняется полностью на каждой итерации внешнего.

**Пример – таблица умножения от 1 до 3:**
```python
for a in range(1, 4):
    for b in range(1, 4):
        print(f"{a} * {b} = {a*b}")
    print("---")
```

### 3. Разбор примеров

#### Пример 1. Вывод всех чисел от N до 1 (обратный порядок)

```python
N = int(input("N = "))
for i in range(N, 0, -1):
    print(i)
```

#### Пример 2. Факториал через `for`

```python
n = int(input("n = "))
fact = 1
for i in range(1, n+1):
    fact *= i
print(f"{n}! = {fact}")
```

#### Пример 3. Поиск суммы цифр числа (без преобразования в строку)

```python
num = int(input("Число: "))
sum_digits = 0
temp = abs(num)
while temp > 0:          # можно и через while, но for здесь неудобен
    sum_digits += temp % 10
    temp //= 10
print("Сумма цифр:", sum_digits)
```

Но для `for` нужно было бы преобразовать в строку:
```python
num_str = input("Число: ")
sum_digits = 0
for ch in num_str:
    if ch.isdigit():
        sum_digits += int(ch)
print(sum_digits)
```

### 5. Возможные решения задач (для преподавателя)

#### Решение задания 1

```python
for i in range(2, 21, 2):
    print(i)
```

Или с шагом 1 и проверкой:
```python
for i in range(2, 21):
    if i % 2 == 0:
        print(i)
```

#### Решение задания 2

```python
N = int(input("Введите N: "))
factorial = 1
for i in range(1, N+1):
    factorial *= i
print(factorial)
```

#### Решение задания 3

```python
N = int(input("Введите N: "))
a, b = 0, 1
for i in range(N):
    print(a, end=" ")
    a, b = b, a + b
print()  # перевод строки
```

**Альтернативное решение с сохранением списка:**
```python
N = int(input("Введите N: "))
fib = [0, 1]
for i in range(2, N):
    fib.append(fib[-1] + fib[-2])
print(*fib[:N])  # выводит первые N чисел
```
