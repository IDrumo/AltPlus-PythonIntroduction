### 2. Теоретическая часть

#### 2.1. Первая программа – `print()`

Функция `print()` выводит текст на экран. Текст заключается в кавычки (одинарные или двойные).

```python
print("Привет, мир!")
```

После запуска программы в консоли появится:
```
Привет, мир!
```

Можно выводить несколько строк:

```python
print("Строка 1")
print("Строка 2")
```

#### 2.2. Переменные

Переменная – это «коробка» с именем, в которой хранятся данные. Имя переменной должно:
- начинаться с буквы или подчёркивания `_`;
- состоять из букв, цифр и подчёркиваний;
- не совпадать с ключевыми словами Python (`if`, `for`, `while` и т.д.).

Примеры хороших имён: `age`, `user_name`, `total_sum`, `x`.

**Присваивание значения:**

```python
x = 5
name = "Анна"
pi = 3.14
```

#### 2.3. Типы данных

- `int` – целые числа (10, -3, 0, 255)
- `float` – вещественные числа (3.14, -0.001, 2.0)
- `str` – строки (текст в кавычках: `"Привет"`, `'Python'`)

Тип переменной определяется автоматически по тому, какое значение ей присвоили.

#### 2.4. Ввод данных – `input()`

Функция `input()` всегда возвращает **строку** (тип `str`). В скобках можно написать подсказку:

```python
name = input("Как тебя зовут? ")
print("Привет,", name)
```

Если нужно ввести число, строку преобразуют в `int` или `float`:

```python
age_str = input("Сколько тебе лет? ")
age = int(age_str)          # преобразование в целое число
```

Или короче:

```python
age = int(input("Сколько тебе лет? "))
```

#### 2.5. Вывод и конкатенация

**Конкатенация** – склеивание строк с помощью `+`.

```python
name = "Маша"
print("Привет, " + name + "!")
```

Но так можно складывать только строки. Нельзя написать `"Ответ: " + 42` – будет ошибка. Число нужно превратить в строку функцией `str()`:

```python
x = 10
print("x = " + str(x))
```

**Удобный способ – f-строки (Python 3.6+):**

```python
x = 10
print(f"x = {x}")
```

Внутри фигурных скобок можно писать переменные и даже выражения: `f"Сумма: {a + b}"`.

**Вывод нескольких значений через запятую** – `print()` автоматически ставит пробел между ними:

```python
a = 5
b = 7
print("Сумма", a, "+", b, "=", a + b)
```

### 3. Разбор примеров

#### Пример 1. Приветствие

```python
name = input("Введите ваше имя: ")
print("Здравствуйте,", name, "!")
```

#### Пример 2. Сложение двух целых чисел

```python
a = int(input("Введите первое число: "))
b = int(input("Введите второе число: "))
s = a + b
print("Сумма =", s)
```

#### Пример 3. Площадь прямоугольника

```python
length = float(input("Длина: "))
width = float(input("Ширина: "))
area = length * width
print("Площадь =", area)
```

### 4. Практические задания

**Задание 1 ★ (лёгкое)**

**Задание 3 ★★★ (на подумать)**  
Пользователь вводит длину и ширину прямоугольника (целые числа). Выведите его площадь и периметр.

*Формулы:*  
Площадь = длина × ширина  
Периметр = 2 × (длина + ширина)

*Пример работы:*
```
Введите длину: 5
Введите ширину: 3
Площадь = 15
Периметр = 16
```
