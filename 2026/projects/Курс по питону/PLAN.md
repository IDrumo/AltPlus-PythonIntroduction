## План занятий по Python для 9 класса (с нуля, с учётом ОГЭ)

Всего **16 занятий** (рекомендуемый режим: 1 занятие в неделю).  
Каждое занятие включает:
- теоретическую часть (10–15 мин),
- разбор примеров,
- **3 практических задания** (лёгкое ★, среднее ★★, на подумать ★★★).

---

### Занятие 1. Первая программа. Переменные и ввод/вывод
**Что изучаем:** установка среды (IDLE / Thonny / Replit), команды `print()`, `input()`, переменные (int, float, str), конкатенация.

**Задачи:**
1. ★ Напишите программу, которая выводит на экран фразу «Привет, мир!».
2. ★★ Запросите у пользователя два целых числа, выведите их сумму.
3. ★★★ Пользователь вводит длину и ширину прямоугольника (целые числа). Выведите его площадь и периметр.

---

### Занятие 2. Условный оператор if-elif-else
**Что изучаем:** сравнения (`>`, `<`, `==`, `!=`, `>=`, `<=`), логические операторы (`and`, `or`, `not`), конструкция `if-elif-else`.

**Задачи:**
1. ★ Запросите число. Если оно чётное, выведите «Чётное», иначе – «Нечётное».
2. ★★ Введите возраст. Программа должна вывести: «ребёнок» (0–12), «подросток» (13–17), «взрослый» (18+).
3. ★★★ Решите квадратное уравнение `ax² + bx + c = 0`. Коэффициенты `a`, `b`, `c` вводятся с клавиатуры. Выведите корни (или сообщение «нет корней»).

---

### Занятие 3. Цикл while
**Что изучаем:** синтаксис `while`, счётчики, бесконечные циклы, операторы `break`, `continue`.

**Задачи:**
1. ★ Выведите на экран все целые числа от 1 до N (N вводится).
2. ★★ Пользователь вводит числа до тех пор, пока не введёт 0. Программа вычисляет сумму всех введённых чисел (0 не учитывается).
3. ★★★ Компьютер «загадывает» случайное число от 1 до 100 (используйте `random.randint`). Игрок пытается угадать его, получая подсказки «больше» / «меньше». После угадывания выводится количество попыток.

---

### Занятие 4. Цикл for. Функция range()
**Что изучаем:** цикл `for`, итерация по последовательности, `range()` с одним, двумя и тремя аргументами.

**Задачи:**
1. ★ Выведите все чётные числа от 2 до 20 включительно (используя `for`).
2. ★★ Вычислите факториал числа N (N вводится). `N! = 1*2*...*N`.
3. ★★★ Выведите первые N чисел Фибоначчи (каждое следующее равно сумме двух предыдущих). Например, для N=6: 0 1 1 2 3 5.

---

### Занятие 5. Строки (индексы, срезы, методы)
**Что изучаем:** индексация и срезы строк, методы `upper()`, `lower()`, `find()`, `replace()`, `split()`, `join()`, проверка `in`.

**Задачи:**
1. ★ Подсчитайте количество пробелов в строке, введённой пользователем.
2. ★★ Переверните строку (например, «Python» → «nohtyP») без использования срезов (можно циклом).
3. ★★★ Проверьте, является ли строка палиндромом (читается одинаково слева направо и справа налево). Игнорируйте регистр и пробелы. Пример: «А роза упала на лапу Азора» → да.

---

### Занятие 6. Списки (list)
**Что изучаем:** создание списков, доступ по индексу, методы `append()`, `insert()`, `remove()`, `pop()`, `sort()`, `len()`, цикл по элементам.

**Задачи:**
1. ★ Дан список чисел `[1, 5, 3, 9, 2]`. Найдите сумму всех элементов.
2. ★★ Найдите наибольший элемент в списке (не используя `max()`). Список вводится с клавиатуры через пробел.
3. ★★★ Удалите из списка все повторяющиеся элементы, оставив только первые вхождения. Порядок сохранить.  
   Пример: `[4, 2, 4, 5, 2, 3]` → `[4, 2, 5, 3]`.

---

### Занятие 7. Обработка цифр числа
**Что изучаем:** выделение цифр числа с помощью цикла `while` (деление на 10), нахождение суммы, произведения, количества цифр.

**Задачи:**
1. ★ Найдите сумму цифр натурального числа N.
2. ★★ Определите количество цифр в числе N (не переводить в строку).
3. ★★★ Составьте новое число из чётных цифр исходного числа, сохранив их порядок. Если чётных цифр нет, вывести 0.  
   Пример: `2381` → `28`, `135` → `0`.

---

### Занятие 8. Функции
**Что изучаем:** определение функций `def`, параметры, `return`, локальные переменные. Знакомство с рекурсией на простых примерах.

**Задачи:**
1. ★ Напишите функцию `greet(name)`, которая выводит «Привет, name!».
2. ★★ Функция `max_of_two(a, b)` возвращает большее из двух чисел.
3. ★★★ Реализуйте рекурсивную функцию для вычисления факториала числа. Объясните, как она работает.

---

### Занятие 9. Кортежи и словари (базово)
**Что изучаем:** неизменяемые кортежи `tuple`, словари `dict` (ключи, значения), методы `keys()`, `values()`, `items()`.

**Задачи:**
1. ★ Создайте словарь с тремя ключами (например, `{'apple': 'яблоко', 'cat': 'кот', 'dog': 'собака'}`). Выведите все ключи.
2. ★★ Пользователь вводит строку. Подсчитайте, сколько раз встречается каждый символ (используйте словарь). Выведите результат.
3. ★★★ Реализуйте «телефонный справочник»: можно добавить контакт (имя и номер) и найти номер по имени. Программа работает в цикле, пока пользователь не введёт «выход».

---

### Занятие 10. Модули random и math
**Что изучаем:** импорт модулей, `random.randint()`, `random.choice()`, `random.shuffle()`, `math.sqrt()`, `math.pi`, `math.floor()`.

**Задачи:**
1. ★ Сгенерируйте и выведите случайное целое число от 1 до 10.
2. ★★ Напишите генератор паролей длины 8, состоящих из букв латиницы (верхний и нижний регистр) и цифр.
3. ★★★ Смоделируйте 1000 бросков двух игральных кубиков. Подсчитайте, сколько раз выпала сумма очков, равная 7. Выведите относительную частоту.

---

### Занятие 11. Работа с файлами
**Что изучаем:** открытие файлов `open()`, режимы `'r'`, `'w'`, `'a'`, методы `read()`, `readlines()`, `write()`, закрытие `close()` (или контекстный менеджер `with`).

**Задачи:**
1. ★ Запишите строку «Python — это здорово!» в файл `message.txt`.
2. ★★ В файле `numbers.txt` построчно записаны целые числа. Прочитайте их и выведите сумму всех чисел.
3. ★★★ Дан CSV-файл с данными учеников: фамилия, оценка.  
   Пример:  
   Иванов,4  
   Петров,5  
   Сидорова,3  
   Вычислите и выведите средний балл.

---

### Занятие 12. Обработка ошибок (try-except)
**Что изучаем:** исключения `ZeroDivisionError`, `ValueError`, `TypeError`, конструкция `try-except-else-finally`.

**Задачи:**
1. ★ Запросите у пользователя два числа и выведите частное. Перехватите деление на ноль, выведите «Ошибка: деление на ноль».
2. ★★ Запрашивайте у пользователя целое число, пока он его не введёт корректно (используйте `try-except`).
3. ★★★ Напишите функцию безопасного ввода даты в формате `ДД.ММ.ГГГГ`. Если введён неверный формат или несуществующая дата (например, 32.13.2025), программа просит повторить ввод.

**Что изучаем:** разбор критериев ОГЭ по заданию 15.1 (написать программу для решения несложной задачи, обычно 5–6 строк).  
Практикуем задачи на «количество элементов, удовлетворяющих условию».

**Задачи:**
1. ★ Посчитать количество чётных чисел среди 10 введённых (цикл `for`).
2. ★★ Дано натуральное число N. Найти количество трёхзначных чисел, кратных 5, в диапазоне от 1 до N.
3. ★★★ Вводится последовательность натуральных чисел, признак конца – 0. Найти количество чисел, у которых сумма цифр равна 10.

### Занятие 14. Решение задач ОГЭ (тип 15.2 – поиск min/max)

**Задачи:**
1. ★ Из 5 введённых чисел найти наименьшее.
2. ★★ Последовательность целых чисел (признак конца – 0). Найти максимальное число, оканчивающееся на 3. Если таких нет, вывести 0.
3. ★★★ Среди натуральных чисел от 1 до N найти число с максимальной суммой цифр. Если таких несколько, вывести наименьшее из них.

### Занятие 15. Обработка строк в ОГЭ
**Что изучаем:** задачи на поиск подстрок, замену, разбиение строк, работу с символами.

**Задачи:**

2. ★★ Замените все пробелы в строке на символ подчёркивания `_`.
3. ★★★ Дана строка, состоящая из слов, разделённых пробелами. Выведите те слова, которые начинаются с заглавной буквы (латиница или кириллица). Пример: «Мама мыла Раму» → «Мама Раму».

### Занятие 16. Итоговое повторение. Решение смешанных задач ОГЭ
**Что изучаем:** повторение всех тем, разбор типичных ошибок, решение трёх задач разного уровня сложности, приближённых к реальному ОГЭ.

**Задачи:**
1. ★ (лёгкая) Напишите программу, которая выводит таблицу умножения на число K (K вводится).  
   Пример для K=3:  
   3 x 1 = 3  
   3 x 2 = 6  
   ...  
   3 x 10 = 30
2. ★★ (средняя) Пользователь вводит натуральное число N. Определите, является ли оно простым (делится только на 1 и на себя).
3. ★★★ (подумать) Дана строка с арифметическим выражением из двух чисел и знака операции (+, -, *, /).  
   Пример: `"12 + 8"`. Программа должна вычислить результат. Обработать возможные ошибки (деление на ноль, некорректный знак, не число). Выполнять без `eval()`.
