### 2. Теоретическая часть

#### 2.1. Операторы сравнения

Операторы сравнения возвращают **логическое значение** – `True` (истина) или `False` (ложь).

| Оператор | Значение               | Пример          | Результат |
|----------|------------------------|-----------------|-----------|
| `==`     | равно                  | `5 == 5`        | `True`    |
| `!=`     | не равно               | `5 != 3`        | `True`    |
| `>`      | больше                 | `5 > 10`        | `False`   |
| `<`      | меньше                 | `3 < 8`         | `True`    |
| `>=`     | больше или равно       | `5 >= 5`        | `True`    |
| `<=`     | меньше или равно       | `4 <= 3`        | `False`   |

**Важно:** `=` – это присваивание, а `==` – сравнение. Не путайте!

#### 2.2. Логические операторы

Позволяют объединять несколько условий.

| Оператор | Действие                     | Пример                                   |
|----------|------------------------------|------------------------------------------|
| `and`    | И – истина, если оба условия истинны | `x > 0 and x < 10` (x от 1 до 9)         |
| `or`     | ИЛИ – истина, если хотя бы одно условие истинно | `x < 0 or x > 100`                       |
| `not`    | НЕ – меняет True на False и наоборот | `not (x == 5)` (то же, что `x != 5`)    |

#### 2.3. Конструкция `if-elif-else`

**Базовый синтаксис:**

```python
if условие:
    # блок кода, если условие истинно
    действие_1
    действие_2
```

Обратите внимание на **двоеточие** и **отступы** (обычно 4 пробела). Все строки с одинаковым отступом принадлежат одному блоку.

**Полная форма:**

```python
if условие_1:
    блок_1
elif условие_2:
    блок_2
elif условие_3:
    блок_3
else:
    блок_иначе
```

- `elif` – сокращение от `else if`. Может быть сколько угодно.
- `else` – выполняется, если ни одно из условий не подошло. Необязателен.

**Пример:**

```python
score = int(input("Сколько баллов? "))
if score >= 90:
    print("Отлично!")
elif score >= 70:
    print("Хорошо")
elif score >= 50:
    print("Удовлетворительно")
else:
    print("Неудовлетворительно")
```

#### 2.4. Вложенные условия

Внутри `if` может быть другой `if`. Но лучше избегать глубокой вложенности, используя `and` / `or`.

```python
x = 10
if x > 0:
    if x < 20:
        print("x между 0 и 20")
# То же самое:
if x > 0 and x < 20:
    print("x между 0 и 20")
```

### 3. Разбор примеров

#### Пример 1. Чётное или нечётное

```python
n = int(input("Введите число: "))
if n % 2 == 0:
    print("Чётное")
else:
    print("Нечётное")
```

`%` – остаток от деления. Если остаток от деления на 2 равен 0, число чётное.

#### Пример 2. Определение времени суток (упрощённо)

```python
hour = int(input("Который час (0-23)? "))
if hour < 6:
    print("Ночь")
elif hour < 12:
    print("Утро")
elif hour < 18:
    print("День")
else:
    print("Вечер")
```

#### Пример 3. Проверка на високосный год

Год високосный, если он делится на 4, но не делится на 100, за исключением годов, делящихся на 400.

```python
year = int(input("Введите год: "))
if (year % 4 == 0 and year % 100 != 0) or (year % 400 == 0):
    print("Високосный")
else:
    print("Не високосный")
```

**Задание 3 ★★★ (на подумать)**  
Решите квадратное уравнение `ax² + bx + c = 0`. Коэффициенты `a`, `b`, `c` вводятся с клавиатуры (вещественные числа). Выведите корни (или сообщение «нет корней»).  
*Напоминание:*  
Дискриминант `D = b² – 4ac`.  
- Если `D < 0` – корней нет.  
- Если `D == 0` – один корень: `x = -b / (2a)`.  
- Если `D > 0` – два корня: `x1 = (-b – sqrt(D)) / (2a)`, `x2 = (-b + sqrt(D)) / (2a)`.  

Для извлечения квадратного корня используйте `import math` и `math.sqrt(D)`.

*Пример работы:*
```
Введите a: 1
Введите b: -3
Введите c: 2
x1 = 1.0
x2 = 2.0
```

#### Решение задания 3

```python
import math

a = float(input("Введите a: "))
b = float(input("Введите b: "))
c = float(input("Введите c: "))

if a == 0:
    print("Это не квадратное уравнение (a=0)")
else:
    D = b**2 - 4*a*c
    if D < 0:
        print("Нет корней")
    elif D == 0:
        x = -b / (2*a)
        print(f"Один корень: {x}")
    else:
        x1 = (-b - math.sqrt(D)) / (2*a)
        x2 = (-b + math.sqrt(D)) / (2*a)
        print(f"x1 = {x1}")
        print(f"x2 = {x2}")
```

**Примечание:** в задании не требуется обрабатывать случай `a == 0` отдельно, но для полноты можно добавить.
