## План курса «Разработка мессенджера на Python»

### Вводная информация
- **Цель курса**: создать полноценный десктопный мессенджер с графическим интерфейсом, поддержкой личных сообщений, истории и списка контактов.
- **Итоговый проект**: клиент-серверное приложение, где несколько пользователей могут обмениваться сообщениями в реальном времени.
- **Исходный код на старте**: простой tkinter-интерфейс (файл `messanger.py`) с заглушками функций.

---

### Занятие 1. Основы сетевого программирования: TCP-сокеты
**Материал**:
- Клиент-серверная модель, IP-адрес, порт.
- Создание сокета: `socket.socket()`, `bind()`, `listen()`, `accept()`, `connect()`.
- Отправка и приём данных: `send()`, `recv()` (блокирующие вызовы).
- Простейший эхо-сервер и эхо-клиент.

**Практическое задание**:
- Написать эхо-сервер, который принимает одно подключение и возвращает тот же текст.
- Написать эхо-клиента, который отправляет сообщение и выводит ответ.
- **Результат**: два скрипта `echo_server.py` и `echo_client.py`.

---

### Занятие 2. Многопоточный сервер для множества клиентов
**Материал**:
- Проблема блокировки: один клиент – один поток.
- Модуль `threading`: создание и запуск потока.
- Обработка каждого клиента в отдельном потоке.
- Синхронизация доступа к общим ресурсам (`threading.Lock`).

**Практическое задание**:
- Переделать эхо-сервер так, чтобы он обслуживал нескольких клиентов одновременно (каждый в своём потоке).
- Добавить логирование подключений и отключений.
- **Результат**: сервер, который может принимать несколько клиентов, но сообщения не пересылаются между ними.

---

### Занятие 3. Простейший групповой чат (broadcast)
**Материал**:
- Глобальный список активных клиентов (сокетов).
- Рассылка сообщения всем подключённым (broadcast).
- Клиент в двух потоках: один читает ввод с клавиатуры, другой принимает сообщения.

**Практическое задание**:
- Реализовать консольный групповой чат: любое сообщение от клиента отправляется всем.
- Клиент работает в консоли (без GUI).
- **Результат**: многопользовательский чат, где все видят сообщения всех.

---

### Занятие 4. Идентификация пользователей и личные сообщения
**Материал**:
- Протокол обмена: текстовые команды (`/login`, `/msg`, `/logout`).
- Сопоставление имени пользователя и сокета.
- Маршрутизация личных сообщений.

**Практическое задание**:
- Сервер обрабатывает команды: `/login username` – запоминает имя, `/msg target text` – пересылает личное сообщение.
- Клиент: при запуске запрашивает имя, отправляет `/login`, затем вводит команды или сообщения.
- **Результат**: чат с поддержкой личных сообщений (в консоли).

---

### Занятие 5. Графический интерфейс клиента на tkinter (основы)
**Материал**:
- Виджеты: `Tk`, `Text`, `Entry`, `Button`, `Listbox`, `Frame`.
- Менеджеры геометрии: `pack()`, `grid()`, `place()`.
- Привязка событий: `bind()`, `command`.

**Практическое задание**:
- Взять заготовку `messanger.py` и доработать:
  - Сделать область чата доступной только для чтения (`state=tk.DISABLED`).
  - Реализовать функцию `send_message()`, которая пока выводит сообщение в `chat_area`.
  - Реализовать `clear_chat()` и `on_contact_select()` (пока просто меняет заголовок окна).
- **Результат**: рабочий GUI, но без сетевой части (локальное отображение сообщений).

---

### Занятие 6. Сетевой клиент в отдельном потоке + очередь сообщений
**Материал**:
- Проблема совмещения tkinter и блокирующих операций.
- Использование `queue.Queue` для передачи данных между потоками.
- Метод `after()` для периодической проверки очереди.

**Практическое задание**:
- Создать класс `NetworkClient`, который подключается к серверу и запускает поток приёма сообщений.
- В потоке приёма сообщения кладутся в очередь.
- В GUI метод `poll_queue()` через `after(100)` забирает сообщения из очереди и выводит в `chat_area`.
- **Результат**: GUI-клиент может отправлять и принимать сообщения (пока без команд).

---

### Занятие 7. Интеграция протокола и аутентификация в GUI
**Материал**:
- Диалоговые окна: `simpledialog`, `messagebox`.
- Отправка команд `/login` и `/register` через сеть.
- Обработка ответов сервера (`OK`, `ERR`).

**Практическое задание**:
- При запуске клиента показывать окно логина (имя, пароль).
- Реализовать регистрацию и вход через сервер.
- После успешного входа сохранять имя пользователя и менять заголовок окна.
- **Результат**: клиент подключается к серверу, проходит аутентификацию.

---

### Занятие 8. База данных SQLite на сервере
**Материал**:
- Введение в SQLite: создание таблиц, вставка, выборка.
- Хеширование паролей (простое: `hashlib.sha256`).
- Сохранение сообщений в БД.

**Практическое задание**:
- Создать на сервере БД `messenger.db` с таблицами `users` (id, username, password_hash) и `messages` (id, from_user, to_user, text, timestamp).
- Реализовать функции `register_user()`, `login_user()`, `save_message()`.
- Сервер теперь проверяет пароли и сохраняет каждое сообщение.
- **Результат**: данные пользователей и сообщений сохраняются между перезапусками сервера.

---

### Занятие 9. История сообщений и команда `/history`
**Материал**:
- SQL-запросы на выборку последних N сообщений между двумя пользователями.
- Формирование ответа сервера.
- Отображение истории в GUI при выборе контакта.

**Практическое задание**:
- Добавить команду `/history username [limit]` на сервере.
- В GUI при выборе контакта отправлять запрос истории и отображать её в `chat_area`.
- **Результат**: при открытии чата подгружается предыдущая переписка (и отправленные, и полученные сообщения).

---

### Занятие 10. Список контактов и онлайн-статус
**Материал**:
- Системные сообщения: рассылка списка всех пользователей с отметкой онлайн.
- Обновление `Listbox` в реальном времени.

**Практическое задание**:
- Сервер периодически (при входе/выходе) рассылает всем клиентам команду `USERLIST` со списком всех зарегистрированных пользователей (онлайн помечены `*`).
- GUI клиента обновляет список контактов, выделяя онлайн-пользователей.
- **Результат**: в левой панели видно всех пользователей и кто сейчас онлайн.

---

### Занятие 11. Отправка и получение личных сообщений через GUI
**Материал**:
- Формирование команды `/msg`.
- Мгновенное отображение отправленных и полученных сообщений.
- Обработка ошибок (пользователь не онлайн и т.д.).

**Практическое задание**:
- Реализовать `send_message()` так, чтобы она отправляла `/msg current_chat text` на сервер.
- Полученные сообщения отображать в `chat_area`, если они относятся к текущему чату.
- Добавить уведомления об ошибках через `messagebox`.
- **Результат**: полноценный обмен сообщениями между двумя клиентами с историей и списком контактов.

---

### Занятие 12. Отладка, рефакторинг, дополнительные возможности
**Материал**:
- Обработка исключений, корректное закрытие соединений.
- Graceful shutdown сервера (обработка Ctrl+C, освобождение порта с `SO_REUSEADDR`).
- Идеи для улучшения: уведомление о наборе текста, групповые чаты, отправка файлов.

**Практическое задание**:
- Провести рефакторинг кода: вынести константы, разбить на модули (уже сделано).
- Добавить обработку ситуации, когда сервер недоступен.
- Реализовать одну дополнительную фичу (например, «печатает...» или групповые чаты).
- Подготовить презентацию проекта.
- **Результат**: стабильный, хорошо структурированный мессенджер, готовый к демонстрации.

## Материалы для преподавателя

### Структура итогового проекта
```
messenger/
├── common/
│   └── protocol.py          # команды, константы, make_message
├── server/
│   ├── server_main.py       # класс ChatServer
│   ├── client_handler.py    # обработка одного клиента
│   └── database.py          # работа с SQLite
├── client/
│   ├── client_main.py       # точка входа
│   ├── gui.py               # tkinter-интерфейс
│   └── network.py           # сокет, поток, очередь
└── messanger.py             # начальная заготовка (первое занятие)
```
