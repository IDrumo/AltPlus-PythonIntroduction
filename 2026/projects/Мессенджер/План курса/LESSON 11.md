# Занятие 11. Отправка и получение личных сообщений через GUI

## Цель занятия

Завершить интеграцию личных сообщений в графический интерфейс. Мы научим клиента:
- отправлять сообщения выбранному контакту (команда `/msg`),
- отображать входящие личные сообщения в нужном чате (только если они относятся к текущему открытому диалогу),
- уведомлять пользователя о новых сообщениях от других контактов (мигание, системное уведомление),
- корректно обрабатывать ошибки (пользователь не онлайн, не существует и т.д.).

В результате GUI-мессенджер станет полностью функциональным: можно выбрать контакт, отправить ему сообщение, получить ответ, увидеть историю и онлайн-статус.

## Теоретическая часть

### Формат личных сообщений в протоколе

Сервер (из занятий 4 и 8) обрабатывает команду `/msg target текст`. При успешной отправке сервер возвращает клиенту-отправителю `OK: ...`, а получателю отправляет сообщение вида:

```
[Личное от отправитель] текст
```

Для broadcast-сообщений (обычный текст без команды) сервер отправляет:

```
[отправитель] текст
```

Клиент должен различать эти форматы, чтобы правильно отображать сообщения и сохранять привязку к контакту.

### Маршрутизация сообщений в GUI

В GUI клиенте:
- Текущий выбранный контакт хранится в переменной `self.current_contact`.
- Входящее сообщение проверяется: если оно адресовано текущему контакту (или от него), то выводится в активную область чата.
- Иначе – нужно показать уведомление (например, подсветить контакт в списке или вывести системное сообщение "Новое сообщение от X").

### Отправка сообщений выбранному контакту

При нажатии "Отправить" (или Enter) клиент:
1. Берёт текст из поля ввода.
2. Определяет текущий контакт (`self.current_contact`).
3. Если контакт выбран, отправляет команду `/msg contact сообщение`.
4. Если контакт не выбран – показывает предупреждение.
5. Очищает поле ввода.
6. (Опционально) Сразу отображает своё сообщение в чате как "Я: текст".

### Обработка ответов сервера

Сервер может ответить на `/msg` сообщением `OK: Сообщение для Bob отправлено` или `ERR: Пользователь Bob не найден`. Клиент должен показать ошибку пользователю (через `messagebox` или временную метку в чате). Успешный ответ обычно не требует отображения, так как сообщение уже показано локально.

## Практика: модификация клиента

### Шаг 1. Изменяем `send_message` для отправки личных сообщений

В классе `MessengerApp` перепишем метод `send_message`:

```python
def send_message(self):
    """Отправить сообщение текущему контакту."""
    message = self.message_entry.get().strip()
    if not message:
        return
    
    if not self.current_contact:
        messagebox.showwarning("Нет контакта", "Выберите контакт из списка")
        return
    
    # Отображаем своё сообщение сразу
    self.display_message(f"Я: {message}")
    # Отправляем команду /msg
    self.network.send(f"/msg {self.current_contact} {message}")
    self.message_entry.delete(0, tk.END)
```

### Шаг 2. Обработка входящих сообщений в `poll_queue`

Нам нужно распознавать:
- Личные сообщения (начинаются с `[Личное от ...]`)
- Общие сообщения (начинаются с `[...]`, но не `[Личное от`)
- Системные сообщения (например, `OK: ...`, `ERR: ...`)
- Команды `USERLIST`, `HISTORY_*`.

```python
def poll_queue(self):
    try:
        while True:
            msg = self.message_queue.get_nowait()
            
            # Команды от сервера
            if msg.startswith("USERLIST:"):
                self.update_contact_list(msg[9:])
                continue
            if msg == "HISTORY_START":
                self.in_history = True
                continue
            if msg == "HISTORY_END":
                self.in_history = False
                continue
            if msg.startswith("OK:") or msg.startswith("ERR:"):
                # Для простоты показываем в чате системные сообщения
                self.display_message(f"[Система] {msg}")
                continue
            
            # Если мы в режиме загрузки истории - выводим как есть
            if self.in_history:
                self.display_message(msg.rstrip('\n'))
                continue
            
            # Обычные сообщения (личные или общие)
            self.handle_incoming_message(msg)
    except queue.Empty:
        pass
    finally:
        self.root.after(100, self.poll_queue)
```

### Шаг 3. Разбор входящего сообщения

Создадим метод `handle_incoming_message`:

```python
def handle_incoming_message(self, raw_msg):
    """Определяет тип сообщения и отображает его в нужном чате."""
    # Личное сообщение
    if raw_msg.startswith("[Личное от "):
        # Формат: "[Личное от Alice] Привет!"
        # Извлекаем отправителя
        end_bracket = raw_msg.find("]")
        if end_bracket == -1:
            self.display_message(raw_msg)
            return
        sender = raw_msg[11:end_bracket]  # после "[Личное от "
        text = raw_msg[end_bracket+2:]   # после "] "
        
        # Если это сообщение от текущего контакта - выводим в чат
        if sender == self.current_contact:
            self.display_message(f"{sender}: {text}")
        else:
            # Сообщение от другого пользователя
            # Показываем системное уведомление и подсвечиваем контакт
            self.display_message(f"[Новое сообщение от {sender}] {text}")
            self.highlight_contact(sender)
    else:
        # Общее сообщение (broadcast) или нераспознанное
        self.display_message(raw_msg)
```

### Шаг 4. Подсветка контакта в списке

Вместо сложностей предложим просто показывать системное сообщение в общем чате и надеяться, что пользователь сам выберет нужный контакт.

### Шаг 5. Обновление заголовка при выборе контакта

В `on_contact_select` мы уже меняем заголовок. Также можно сбросить флаг "нового сообщения" для этого контакта (если бы мы его хранили).

```python
def on_contact_select(self, event):
    selection = self.contacts_listbox.curselection()
    if selection:
        contact = self.contacts_listbox.get(selection[0])
        # Убираем возможные префиксы (● или другие)
        if contact.startswith("●"):
            contact = contact[2:]
        self.current_contact = contact.strip()
        self.root.title(f"Мессенджер - Чат с {self.current_contact}")
        self.clear_chat()
        self.in_history = True
        self.network.send(f"/history {self.current_contact}")
```
