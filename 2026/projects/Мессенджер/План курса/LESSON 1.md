## Теоретическая часть

### Клиент-серверная модель

В большинстве сетевых приложений один компьютер (сервер) предоставляет какой-то сервис, а другие компьютеры (клиенты) этим сервисом пользуются. Сервер всегда работает в режиме ожидания подключений, клиент сам инициирует соединение.

**Примеры:** веб-сервер и браузер, почтовый сервер и почтовая программа, наш будущий мессенджер.

### IP-адрес и порт

- **IP-адрес** – уникальный идентификатор устройства в сети (например, `127.0.0.1` – локальный компьютер, `192.168.1.10` – адрес в локальной сети).
- **Порт** – номер (от 0 до 65535), который позволяет на одном компьютере запустить много разных серверов. Например, веб-сервер обычно использует порт 80, наш мессенджер может использовать порт 12345.

Связка `(IP, порт)` однозначно определяет процесс на машине, который ждёт подключения.

### Что такое сокет?

Сокет – программный интерфейс для отправки и получения данных по сети. В Python сокет создаётся функцией `socket.socket()`.

Для TCP-сокетов (надёжная передача с установкой соединения) используется тип `SOCK_STREAM`.

### Основные методы сокетов (серверная сторона)

| Метод                | Назначение                                      |
|----------------------|-------------------------------------------------|
| `socket()`           | Создать новый сокет                             |
| `bind(('ip', port))` | Привязать сокет к IP и порту                    |
| `listen(backlog)`    | Перевести сокет в режим ожидания подключений    |
| `accept()`           | Принять входящее соединение (блокирующий вызов) |
| `recv(buffer_size)`  | Прочитать данные из сокета                      |
| `send(data)`         | Отправить данные                                |
| `close()`            | Закрыть сокет                                   |

### Основные методы сокетов (клиентская сторона)

| Метод | Назначение |
|-------|-------------|
| `socket()` | Создать сокет |
| `connect(('ip', port))` | Подключиться к серверу |
| `send(data)` | Отправить запрос |
| `recv(buffer_size)` | Получить ответ |
| `close()` | Закрыть соединение |

### Блокирующие вызовы

`accept()`, `recv()`, `connect()` – блокирующие. Это значит, что программа останавливается в этой точке, пока не произойдёт событие (не придёт клиент, не придут данные, не установится соединение). В будущем мы научимся обходить это с помощью потоков, но на первом занятии блокировка – наше преимущество, так как код становится линейным и простым.

## Практика: эхо-сервер

Эхо-сервер – классический учебный пример. Сервер ждёт подключения, принимает сообщение от клиента и отправляет это же сообщение обратно («echo» – эхо).

### Пошаговая разработка

1. **Импортируем модуль `socket`**  
   ```python
   import socket
   ```

2. **Создаём сокет**  
   ```python
   server_socket = socket.socket(socket.AF_INET, socket.SOCK_STREAM)
   ```
   - `AF_INET` – семейство протоколов IPv4.
   - `SOCK_STREAM` – надёжная потоковая передача (TCP).

3. **Привязываем к адресу и порту**  
   ```python
   HOST = '127.0.0.1'  # localhost – только для тестов внутри одной машины
   PORT = 12345
   server_socket.bind((HOST, PORT))
   ```

4. **Начинаем слушать**  
   ```python
   server_socket.listen(5)   # 5 – максимальная очередь ожидающих подключений
   print(f"Сервер запущен на {HOST}:{PORT}, ожидание подключений...")
   ```

5. **Принимаем клиента**  
   ```python
   client_socket, client_address = server_socket.accept()
   print(f"Подключился клиент {client_address}")
   ```

6. **Принимаем данные и отправляем обратно**  
   ```python
   while True:
       data = client_socket.recv(1024)   # максимум 1024 байта за раз
       if not data:                      # клиент закрыл соединение
           break
       print(f"Получено: {data.decode('utf-8')}")
       client_socket.send(data)          # отправляем те же данные
   ```

7. **Закрываем соединение**  
   ```python
   client_socket.close()
   server_socket.close()
   ```

### Полный код эхо-сервера (`echo_server.py`)

```python
import socket

def main():
    HOST = '127.0.0.1'
    PORT = 12345

    # 1. Создаём TCP-сокет
    server_socket = socket.socket(socket.AF_INET, socket.SOCK_STREAM)
    
    # Опция SO_REUSEADDR позволяет сразу перезапустить сервер после закрытия
    server_socket.setsockopt(socket.SOL_SOCKET, socket.SO_REUSEADDR, 1)
    
    # 2. Привязываем к адресу и порту
    server_socket.bind((HOST, PORT))
    
    # 3. Начинаем слушать
    server_socket.listen(5)
    print(f"Эхо-сервер запущен на {HOST}:{PORT}")
    
    # 4. Принимаем одно подключение (для простоты)
    client_socket, client_addr = server_socket.accept()
    print(f"Подключился клиент: {client_addr}")
    
    # 5. Обмениваемся данными
    while True:
        # Получаем данные от клиента
        data = client_socket.recv(1024)
        if not data:
            # Клиент разорвал соединение
            break
        print(f"Получено: {data.decode('utf-8')}")
        
        # Отправляем их обратно
        client_socket.send(data)
    
    # 6. Закрываем сокеты
    client_socket.close()
    server_socket.close()
    print("Сервер завершил работу.")

if __name__ == "__main__":
    main()
```

## Практика: эхо-клиент

Клиент подключается к серверу, запрашивает у пользователя ввод строки, отправляет её на сервер и печатает полученный ответ.

### Полный код эхо-клиента (`echo_client.py`)

```python
import socket

def main():
    HOST = '127.0.0.1'
    PORT = 12345

    # Создаём сокет
    client_socket = socket.socket(socket.AF_INET, socket.SOCK_STREAM)
    
    # Подключаемся к серверу
    client_socket.connect((HOST, PORT))
    print(f"Подключено к серверу {HOST}:{PORT}")
    
    while True:
        # Вводим сообщение с клавиатуры
        message = input("Введите сообщение (или 'exit' для выхода): ")
        if message.lower() == 'exit':
            break
        
        # Отправляем сообщение серверу
        client_socket.send(message.encode('utf-8'))
        
        # Получаем ответ
        response = client_socket.recv(1024)
        print(f"Ответ сервера: {response.decode('utf-8')}")
    
    client_socket.close()
    print("Клиент завершил работу.")

if __name__ == "__main__":
    main()
```

## Разбор кода и частые ошибки

### Ошибка `Address already in use`
После остановки сервера порт может оставаться занятым на несколько секунд. Чтобы избежать этого, мы добавили строку:
```python
server_socket.setsockopt(socket.SOL_SOCKET, socket.SO_REUSEADDR, 1)
```
Она позволяет немедленно переиспользовать порт.

### Кодировка строк
Сокеты работают с байтами, а не со строками. Поэтому перед отправкой нужно преобразовать строку в байты:  
`message.encode('utf-8')`  
А при получении – декодировать:  
`data.decode('utf-8')`

### Размер буфера `recv(1024)`
Мы читаем не более 1024 байт за раз. Если сообщение длиннее, его придётся читать в цикле. Для учебного примера 1024 достаточно.

### Пустое сообщение (`if not data: break`)
Когда клиент закрывает сокет, `recv()` возвращает пустую строку байтов `b''`. Это сигнал, что соединение разорвано.
