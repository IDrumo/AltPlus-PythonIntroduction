# Занятие 10. Список контактов и онлайн-статус

## Цель занятия

Научиться динамически обновлять список контактов в GUI, показывая, какие пользователи сейчас онлайн. Сервер будет поддерживать актуальный список всех зарегистрированных пользователей и при каждом изменении (вход/выход) рассылать всем клиентам команду `USERLIST` с полным списком пользователей и пометкой `*` для онлайн. Клиент будет обновлять `Listbox`, выделяя онлайн-пользователей (например, жирным шрифтом или зелёным цветом). Это сделает мессенджер более информативным и удобным.

---

## Теоретическая часть

### Зачем нужен список контактов?

В реальном мессенджере пользователь видит не только тех, с кем уже общался, но и всех зарегистрированных пользователей. Также важно знать, кто сейчас онлайн, чтобы отправлять личные сообщения с уверенностью в доставке.

### Подходы к обновлению списка

1. **Периодический опрос** – клиент каждые N секунд запрашивает список. Неэффективно.
2. **Push-уведомления от сервера** – сервер сам отправляет обновления при изменении списка. Это лучший вариант.

Мы будем использовать второй подход. Сервер при:
- успешном входе пользователя,
- выходе пользователя (штатном или по таймауту)

рассылает всем активным клиентам сообщение специального формата, например:

```
USERLIST: alice,bob*,charlie,diana*
```

Где `*` означает, что пользователь онлайн. Отправитель может получить список, где он сам отмечен как онлайн.

### Формат команды

Сервер отправляет клиенту команду `USERLIST` со списком, разделённым запятыми. Онлайн-пользователи помечаются звёздочкой.

Пример: `USERLIST: alice*,bob,charlie*,diana`

Клиент, получив такую строку, парсит её и обновляет список контактов.

### Синхронизация данных на сервере

Сервер должен хранить:
- всех зарегистрированных пользователей (из БД),
- онлайн-пользователей (словарь `users`).

При каждом изменении онлайн-статуса (вход/выход) сервер формирует полный список всех пользователей, помечая онлайн, и рассылает его всем.

### Отображение в GUI

В tkinter `Listbox` не поддерживает разные цвета для разных строк без дополнительных ухищрений. Простейший способ – отмечать онлайн пользователей символом `●` (зелёный кружок) или `(online)` после имени. Более продвинутый – использовать `Treeview` или кастомный виджет. Для учебного проекта достаточно текстовой пометки.

## Практика: модификация сервера

Добавим на сервер функцию `broadcast_userlist()`, которая формирует список всех пользователей (из БД) и рассылает его.

### Шаг 1. Получение всех пользователей из БД

В классе `Database` добавим метод:

```python
def get_all_users(self):
    """Возвращает список всех зарегистрированных имён."""
    with self.lock:
        conn = sqlite3.connect(self.db_file)
        cursor = conn.cursor()
        cursor.execute('SELECT username FROM users')
        rows = cursor.fetchall()
        conn.close()
    return [row[0] for row in rows]
```

### Шаг 2. Функция рассылки списка

В сервере (например, `chat_server.py`) добавим:

```python
def broadcast_userlist():
    """Отправить всем клиентам актуальный список пользователей (онлайн помечены *)."""
    all_users = db.get_all_users()
    # Помечаем онлайн
    with users_lock:
        online_set = set(users.keys())
    marked = []
    for u in all_users:
        if u in online_set:
            marked.append(f"{u}*")
        else:
            marked.append(u)
    userlist_str = ",".join(marked)
    message = f"USERLIST:{userlist_str}"
    broadcast(message)   # рассылаем всем, включая отправителя
```

### Шаг 3. Вызов рассылки при изменениях

- После успешного `/login` (когда пользователь становится онлайн):
  ```python
  # ... после добавления в словарь users ...
  broadcast_userlist()
  ```

- При выходе пользователя (в `/logout` или при разрыве соединения):
  ```python
  # перед удалением из users, но после того как username ещё известен
  broadcast_userlist()
  ```

Также при запуске сервера можно один раз отправить всем текущий список, но обычно клиенты подключаются позже.

## Практика: модификация клиента

Клиент должен распознавать сообщения, начинающиеся с `USERLIST:`, парсить список и обновлять `Listbox`.

### Шаг 1. Парсинг и обновление Listbox

Добавим в класс `MessengerApp` метод:

```python
def update_contact_list(self, userlist_str):
    """Обновляет список контактов. Формат: "alice*,bob,charlie*" """
    # Очищаем текущий список
    self.contacts_listbox.delete(0, tk.END)
    # Разбираем строку
    users = userlist_str.split(',')
    for user in users:
        if user.endswith('*'):
            name = user[:-1]
            # Добавляем с пометкой (онлайн)
            self.contacts_listbox.insert(tk.END, f"● {name}")
        else:
            self.contacts_listbox.insert(tk.END, f"  {user}")
    # Можно также сохранить список для быстрого доступа
    self.contact_list = [u.rstrip('*') for u in users]
```

### Шаг 2. Обработка входящих сообщений

В методе `poll_queue` (или `display_message`) нужно проверить, начинается ли сообщение с `USERLIST:`.

```python
def poll_queue(self):
    try:
        while True:
            msg = self.message_queue.get_nowait()
            if msg.startswith("USERLIST:"):
                # Обновляем список контактов
                userlist_data = msg[9:]  # отрезаем "USERLIST:"
                self.update_contact_list(userlist_data)
            else:
                # Обычное сообщение (история или чат)
                self.display_message(msg)
    except queue.Empty:
        pass
    finally:
        self.root.after(100, self.poll_queue)
```

### Шаг 3. Сохранение текущего выбранного контакта

После обновления списка может измениться порядок или исчезнуть выбранный контакт. Желательно сохранять выделение, если контакт ещё существует. Для простоты можно сбросить выделение.

## Расширенный вариант: цветовая индикация (опционально)

Стандартный `Listbox` не позволяет менять цвет отдельных строк без переопределения. Можно использовать `tkinter.ttk.Treeview` или создать кастомный виджет. Для базового курса достаточно текстовой пометки (`●`). Но если хочется цвет, можно использовать `Canvas` или `Text` виджет. Приведём упрощённый способ с изменением цвета фона строки через `itemconfig` – но `Listbox` этого не поддерживает. Поэтому оставим символьную пометку.

## Полный пример кода клиента (фрагменты)

Приведём только изменённые части.

```python
class MessengerApp:
    # ... __init__ и другие методы ...
    
    def update_contact_list(self, userlist_str):
        """Обновляет список контактов."""
        self.contacts_listbox.delete(0, tk.END)
        users = userlist_str.split(',')
        for user in users:
            if user.endswith('*'):
                name = user[:-1]
                self.contacts_listbox.insert(tk.END, f"● {name}")
            else:
                self.contacts_listbox.insert(tk.END, f"  {user}")
        # Сохраняем чистые имена для дальнейшего использования
        self.contact_names = [u.rstrip('*') for u in users]
    
    def poll_queue(self):
        try:
            while True:
                msg = self.message_queue.get_nowait()
                if msg.startswith("USERLIST:"):
                    userlist_data = msg[9:]
                    self.update_contact_list(userlist_data)
                elif msg.startswith("HISTORY_START"):
                    self.in_history = True
                elif msg.startswith("HISTORY_END"):
                    self.in_history = False
                else:
                    if self.in_history:
                        self.display_message(msg.rstrip('\n'))
                    else:
                        self.display_message(msg)
        except queue.Empty:
            pass
        finally:
            self.root.after(100, self.poll_queue)
```
