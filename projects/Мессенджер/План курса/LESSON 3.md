# Занятие 3. Простейший групповой чат (broadcast)

## Цель занятия

Научиться реализовывать широковещательную рассылку сообщений (broadcast) – когда сообщение, отправленное одним клиентом, получают все подключённые клиенты. Это основа любого группового чата. Мы также модифицируем клиент так, чтобы он мог одновременно отправлять сообщения и получать сообщения от других (используя два потока).

---

## Теоретическая часть

### Broadcast (широковещательная рассылка)

В нашем многопоточном сервере каждый клиент обрабатывается в отдельном потоке. Если мы хотим, чтобы сообщение от одного клиента получили все остальные, сервер должен:

1. Хранить список всех активных клиентов (их сокетов).
2. Когда приходит сообщение от клиента, пройтись по списку и отправить это сообщение каждому (кроме, возможно, отправителя).
3. При отключении клиента удалить его из списка.

### Глобальный список клиентов

Список сокетов будет разделяемым ресурсом – несколько потоков могут одновременно его читать и изменять. Поэтому нужна синхронизация с помощью `threading.Lock`.

```python
clients = []           # список сокетов
clients_lock = threading.Lock()
```

Добавление клиента:
```python
with clients_lock:
    clients.append(client_socket)
```

Удаление клиента:
```python
with clients_lock:
    clients.remove(client_socket)
```

Рассылка всем:
```python
with clients_lock:
    for c in clients:
        try:
            c.send(message.encode())
        except:
            # Если отправить не удалось, клиент, вероятно, отключился
            # (будет удалён позже)
            pass
```

### Проблема клиента: два потока

Клиент тоже должен решить проблему блокировки:
- Поток A: читает ввод с клавиатуры (`input()`) и отправляет сообщения на сервер.
- Поток B: постоянно получает сообщения от сервера (`recv()`) и выводит их на экран.

Если бы мы делали это в одном потоке, то либо не могли бы вводить сообщения, пока ждём новые, либо не могли бы принимать, пока вводим.

### Протокол (простейший)

Пока без команд – просто отправляем текст. Сервер принимает текст и рассылает всем. Каждое сообщение будет помечено именем отправителя? Пока нет – это будет анонимный чат. На следующем занятии добавим идентификацию.

## Практика: сервер с broadcast

### Пошаговая разработка сервера

1. **Глобальные переменные и блокировка**:
   ```python
   active_clients = []  # список сокетов
   clients_lock = threading.Lock()
   ```

2. **Функция broadcast**:
   ```python
   def broadcast(message, sender_socket=None):
       """Отправить сообщение всем клиентам, кроме отправителя."""
       with clients_lock:
           for client in active_clients:
               if client != sender_socket:
                   try:
                       client.send(message.encode('utf-8'))
                   except:
                       # Если клиент недоступен, удалим его позже
                       pass
   ```

3. **Обработчик клиента**:
   - Добавляем сокет в список.
   - В цикле получаем сообщения.
   - Для каждого сообщения вызываем `broadcast()`.
   - При отключении удаляем сокет из списка.

4. **Защита от ошибок отправки**: Если при рассылке клиент недоступен, мы не удаляем его сразу (чтобы не модифицировать список во время итерации). Лучше собрать список "мёртвых" клиентов и удалить после.

### Полный код сервера (`chat_server.py`)

```python
import socket
import threading
import logging

logging.basicConfig(level=logging.INFO, format='%(asctime)s - %(levelname)s - %(message)s')

active_clients = []      # список сокетов активных клиентов
clients_lock = threading.Lock()

def broadcast(message, sender_socket=None):
    """Отправить сообщение всем подключённым клиентам, кроме отправителя."""
    with clients_lock:
        for client in active_clients:
            if client != sender_socket:
                try:
                    client.send(message.encode('utf-8'))
                except Exception as e:
                    logging.error(f"Не удалось отправить сообщение клиенту: {e}")
                    # Не удаляем здесь, чтобы не менять список во время итерации

def remove_dead_clients():
    """Удалить клиентов, у которых соединение закрыто."""
    with clients_lock:
        dead = []
        for client in active_clients:
            try:
                # Отправляем пустое сообщение как проверку соединения
                client.send(b'')
            except:
                dead.append(client)
        for d in dead:
            active_clients.remove(d)
            logging.info(f"Клиент удалён из списка (недоступен)")

def handle_client(client_socket, client_address):
    logging.info(f"Новый клиент: {client_address}")
    # Добавляем клиента в список
    with clients_lock:
        active_clients.append(client_socket)
    
    try:
        while True:
            data = client_socket.recv(1024)
            if not data:
                break
            message = data.decode('utf-8')
            logging.info(f"Сообщение от {client_address}: {message}")
            # Рассылаем всем, кроме отправителя
            broadcast(message, sender_socket=client_socket)
    except ConnectionResetError:
        logging.warning(f"Клиент {client_address} оборвал соединение")
    except Exception as e:
        logging.error(f"Ошибка при обработке {client_address}: {e}")
    finally:
        # Удаляем клиента из списка
        with clients_lock:
            if client_socket in active_clients:
                active_clients.remove(client_socket)
        client_socket.close()
        logging.info(f"Клиент {client_address} отключился")

def main():
    HOST = '127.0.0.1'
    PORT = 12345

    server = socket.socket(socket.AF_INET, socket.SOCK_STREAM)
    server.setsockopt(socket.SOL_SOCKET, socket.SO_REUSEADDR, 1)
    server.bind((HOST, PORT))
    server.listen(5)
    logging.info(f"Чат-сервер запущен на {HOST}:{PORT}")

    try:
        while True:
            client_sock, client_addr = server.accept()
            thread = threading.Thread(target=handle_client, args=(client_sock, client_addr))
            thread.start()
    except KeyboardInterrupt:
        logging.info("Сервер остановлен вручную")
    finally:
        server.close()

if __name__ == "__main__":
    main()
```

## Практика: клиент с двумя потоками

Клиент должен:
- Создать сокет и подключиться к серверу.
- Запустить поток для приёма сообщений (получает и выводит на экран).
- В главном потоке бесконечно читать ввод с клавиатуры и отправлять на сервер.

### Полный код клиента (`chat_client.py`)

```python
import socket
import threading
import sys

def receive_messages(client_socket):
    """Поток для получения сообщений от сервера."""
    try:
        while True:
            data = client_socket.recv(1024)
            if not data:
                print("\nСоединение с сервером разорвано.")
                break
            message = data.decode('utf-8')
            # Выводим сообщение, аккуратно вставляя его в консоль
            print(f"\n[Новое сообщение] {message}")
            print("> ", end="", flush=True)   # повторяем приглашение ввода
    except:
        print("Ошибка при получении сообщения.")
    finally:
        client_socket.close()
        sys.exit(0)

def main():
    HOST = '127.0.0.1'
    PORT = 12345

    client = socket.socket(socket.AF_INET, socket.SOCK_STREAM)
    try:
        client.connect((HOST, PORT))
        print(f"Подключено к чат-серверу {HOST}:{PORT}")
    except:
        print("Не удалось подключиться к серверу")
        return

    # Запускаем поток для приёма сообщений
    recv_thread = threading.Thread(target=receive_messages, args=(client,))
    recv_thread.daemon = True   # поток завершится при выходе из main
    recv_thread.start()

    # Главный поток занимается отправкой
    try:
        while True:
            message = input("> ")
            if not message:
                continue
            if message.lower() == '/quit':
                break
            client.send(message.encode('utf-8'))
    except KeyboardInterrupt:
        print("\nЗавершение клиента...")
    finally:
        client.close()

if __name__ == "__main__":
    main()
```

## Разбор кода и возможные проблемы

### Зачем нужен `daemon=True` в клиенте?

Поток приёма сообщений помечен как демонический (`daemon=True`). Это означает, что он автоматически завершится, когда завершится главный поток (при вводе `/quit` или `Ctrl+C`). Иначе пришлось бы вручную сигнализировать о выходе.

### Проблема с выводом в консоли

Когда мы выводим полученное сообщение, оно может прервать строку ввода. В коде мы используем:
```python
print(f"\n[Новое сообщение] {message}")
print("> ", end="", flush=True)
```
Это не идеально, но для консольного чата приемлемо. Альтернатива – использовать библиотеку `curses` или просто смириться с наложением текста.

### Удаление "мёртвых" клиентов на сервере

В нашем сервере при рассылке мы не удаляем недоступных клиентов сразу, а при выходе из `handle_client` удаляем их из списка. Если клиент отключается нештатно (обрыв сети), то `recv()` может зависнуть. Чтобы решить эту проблему, можно добавить таймаут или механизм ping-pong. Для учебного чата достаточно того, что есть.

### Блокировки в broadcast

В функции `broadcast` мы захватываем блокировку на время чтения списка. При отправке сообщения конкретному клиенту мы не держим блокировку – это правильно, чтобы не блокировать другие потоки.
