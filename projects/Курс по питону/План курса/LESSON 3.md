### 2. Теоретическая часть

#### 2.1. Что такое цикл?

Цикл – это конструкция, которая повторяет блок кода несколько раз.  
`while` – цикл **с предусловием**: повторяет код, **пока** условие истинно. Как только условие становится ложным, цикл заканчивается.

**Синтаксис:**

```python
while условие:
    # тело цикла – выполняется, пока условие True
    действие_1
    действие_2
```

Важно, чтобы внутри цикла что-то менялось, иначе условие останется истинным навсегда – получится **бесконечный цикл**.

#### 2.2. Простой пример – счётчик

Выведем числа от 1 до 5:

```python
i = 1          # начальное значение счётчика
while i <= 5:
    print(i)
    i = i + 1  # увеличиваем счётчик
```

Вывод:
```
1
2
3
4
5
```

Как только `i` станет равным 6, условие `i <= 5` станет ложным, цикл остановится.

#### 2.3. Бесконечные циклы и их остановка

Если условие всегда истинно, цикл никогда не закончится. Например:

```python
while True:
    print("Бесконечность")
```

Такой цикл можно прервать с помощью оператора `break`.  
`break` – немедленно выходит из цикла (даже если условие цикла всё ещё истинно).

```python
while True:
    ответ = input("Введите 'выход' чтобы остановиться: ")
    if ответ == "выход":
        break
    print("Вы ввели:", ответ)
```

#### 2.4. Оператор `continue`

`continue` – пропускает остаток текущей итерации и переходит к следующей (проверке условия).

```python
i = 0
while i < 10:
    i += 1
    if i % 2 == 0:
        continue   # чётные числа не печатаем
    print(i)
```

Выведет нечётные числа от 1 до 9.

#### 2.5. Типичные схемы использования `while`

**Схема счётчика:**
```python
i = начальное_значение
while i <= конечное_значение:
    # делаем что-то с i
    i += 1   # шаг
```

**Схема «ввод до маркера»:**
```python
x = int(input("Введите число (0 для выхода): "))
while x != 0:
    # обрабатываем x
    x = int(input("Введите число (0 для выхода): "))
```

**Схема с флагом:**
```python
found = False
while not found:
    # ищем что-то
    if условие:
        found = True
```

### 3. Разбор примеров

#### Пример 1. Сумма чисел от 1 до N

```python
N = int(input("Введите N: "))
i = 1
total = 0
while i <= N:
    total += i   # то же, что total = total + i
    i += 1
print(f"Сумма от 1 до {N} = {total}")
```

#### Пример 2. Проверка пароля (3 попытки)

```python
password = "python123"
attempts = 3
while attempts > 0:
    user_input = input("Введите пароль: ")
    if user_input == password:
        print("Доступ разрешён!")
        break
    else:
        attempts -= 1
        if attempts > 0:
            print(f"Неверно. Осталось попыток: {attempts}")
        else:
            print("Доступ запрещён.")
```

#### Пример 3. Вычисление факториала через `while`

```python
n = int(input("n = "))
factorial = 1
i = 1
while i <= n:
    factorial *= i
    i += 1
print(f"{n}! = {factorial}")
```

### 5. Возможные решения задач (для преподавателя)

#### Решение задания 1

```python
N = int(input("Введите N: "))
i = 1
while i <= N:
    print(i)
    i += 1
```

#### Решение задания 2

```python
total = 0
num = int(input("Введите число: "))
while num != 0:
    total += num
    num = int(input("Введите число: "))
print(f"Сумма = {total}")
```

#### Решение задания 3

```python
import random

secret = random.randint(1, 100)
attempts = 0
print("Я загадал число от 1 до 100. Угадай!")

while True:
    guess = int(input("Ваша догадка: "))
    attempts += 1
    if guess < secret:
        print("Больше")
    elif guess > secret:
        print("Меньше")
    else:
        print(f"Поздравляю! Вы угадали за {attempts} попыток.")
        break
```
